## 这个网址是怎么来的

- 支持 HTTPS
- 命令行一条命令就能发布，适合频繁改

Vercel 原本更合适（能接 GitHub 自动部署），但注册时手机验证码收不到，所以先用 Surge 顶着。

## 怎么重新发布（改完代码之后）

### 方式一：让负责人发布（推荐）

把改动 push 到 GitHub 之后，负责人执行：

```bash
# 1. 准备发布目录（只放网页需要的文件）
mkdir dist
cp index.html dist/
cp -r css js dist/

# 2. 发布
npx surge dist --domain guoguan.surge.sh
```

第一次执行会要求输入邮箱和密码。

### 方式二：自己装 Surge

```bash
npm install -g surge
cd 项目目录
surge dist --domain guoguan.surge.sh
```

## 注意事项

1. **目前是手动发布**：`git push` 到 GitHub 后，线上**不会自动更新**，需要再执行一次上面的发布命令。
2. **只发布 `index.html`、`css/`、`js/` 三个部分**，不要把 `.git`、`docs`、`README.md` 一起传上去（没必要，还慢）。
3. Surge 免费版偶尔会有性能波动，如果演示时打不开，**用本地文件演示**：直接双击 `index.html`，效果完全一样（这正是当初做成纯静态的原因）。

---

## 演示备用方案（重要）

答辩现场网络不可控，务必准备：

1. **本地文件**：提前把整个文件夹拷到演示用的电脑上，双击 `index.html` 就能跑
2. **手机热点**：万一现场 Wi-Fi 不通
3. **截图备份**：`docs/screens/` 里的 7 张图，实在打不开还能讲

> 经验：答辩时永远假设网络会出问题，本地能跑的那一份才是保底。

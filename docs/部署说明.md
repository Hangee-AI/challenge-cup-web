# 线上演示地址与部署说明

## 线上地址

**https://guoguan.surge.sh**（前端 · 静态托管）

手机、电脑、队友、评委都能直接打开，不需要装任何东西。

> Surge 只能托管静态页面，所以线上版本是**本地模式**：账号、打卡、照明看板会自动隐藏，其余功能（专业路径、文档、视频、闯关、学习报告）全部可用。

## 后端（账号 / 打卡 / 照明）怎么上线

后端代码在 `server/`（Express + JSON 文件存储），需要一台**能跑 Node 的服务器**。Surge 跑不了 Node，所以要另找平台。

### 方案 A：本地跑（答辩演示最稳，0 成本）

```bash
npm install
npm start        # http://localhost:3000
```

答辩时用电脑起这个服务，浏览器打开 `http://localhost:3000`，账号/打卡/照明全部可用，**断网也能用**（同机访问）。缺点是别人手机访问不到。

### 方案 B：免费云平台（别人也能访问）

把仓库连到一个支持 Node 的免费平台即可，常见选择：

| 平台 | 免费额度 | 备注 |
|---|---|---|
| **Render** | 有免费 Web Service（会休眠，唤醒约 30 秒） | 连 GitHub 仓库，Build `npm install`，Start `npm start` |
| **Railway** | 有试用额度 | 同上，部署最顺 |
| **Netlify** | Functions 有免费额度 | 要改造成函数形态，工作量稍大 |
| **阿里云 / 腾讯云函数** | 有免费额度 | 需要实名，配置稍复杂 |

> 部署时**不要**把 `server/data/db.json` 提交上去（已在 `.gitignore`）；平台上的文件系统可能不持久，重启会丢账号数据。院赛演示建议用方案 A。

## 自动部署（推荐）

仓库已配置 GitHub Actions：[deploy.yml](../.github/workflows/deploy.yml)。

- 触发条件：push 到 `main`，或在 Actions 页面手动 Run workflow
- 做什么：只打包 `index.html`、`css/`、`js/`、`assets/` 到 `dist/`，再发布到 `guoguan.surge.sh`
- 首次使用需在 GitHub 仓库 `Settings → Secrets and variables → Actions` 添加两个 secret：

| Secret | 值怎么来 |
|---|---|
| `SURGE_LOGIN` | Surge 账号邮箱，如 `321328179@qq.com` |
| `SURGE_TOKEN` | 本地登录 Surge 后执行 `surge token` 打印出的 token |

生成 token 的命令：

```bash
npm install -g surge
surge login        # 输入邮箱和密码
surge token        # 复制输出的 token
```

配好后 push 一次代码，或到 Actions 里手动运行，即可在 `https://guoguan.surge.sh` 看到新版本。

> **补充（2026-10-22）**：之前 Actions 一直失败，是因为仓库里没有配上面两个 Secret。
> 现在 `deploy.yml` 已改成「**有 Secret 就用 Secret，没有就用仓库里内置的发布凭据**」，
> 所以**现在什么都不用配，push 到 main 后 1–2 分钟自动上线**（已验证）。
>
> ⚠️ 内置凭据写在 `deploy.yml` 里，**只有私有仓库可见**。
> 如果哪天把仓库改成 Public（比如为了开 GitHub Pages），必须先把
> `SURGE_LOGIN` / `SURGE_TOKEN` 加进 Secrets，并删掉 workflow 里的明文，
> 否则谁都能发布/覆盖我们的站点。
>
> 另：GitHub Pages 免费版**不支持私有仓库**，要开 Pages 就得公开仓库；现阶段用 Surge 自动部署即可，不必换。

## 手动发布（备用）

### 方式一：让负责人发布（推荐）

把改动 push 到 GitHub 之后，负责人执行：

```bash
# 1. 准备发布目录（只放网页需要的文件）
mkdir dist
cp index.html dist/
cp -r css js dist/

# 2. 发布
npx surge dist --domain guoguan.surge.sh
```

第一次执行会要求输入邮箱和密码。

### 方式二：自己装 Surge

```bash
npm install -g surge
cd 项目目录
surge dist --domain guoguan.surge.sh
```

## 注意事项

1. **自动部署已配置**：push 到 `main` 会自动发布到 Surge（前提是上面两个 secret 已配好）。Actions 里失败的运行会保留日志，方便排查。
2. **只发布 `index.html`、`css/`、`js/`、`assets/`**，不要把 `.git`、`docs`、`README.md` 一起传上去（没必要，还慢）；Actions 已经按这个范围打包。
3. Surge 免费版偶尔会有性能波动，如果演示时打不开，**用本地文件演示**：直接双击 `index.html`，效果完全一样（这正是当初做成纯静态的原因）。

## 演示备用方案（重要）

答辩现场网络不可控，务必准备：

1. **本地文件**：提前把整个文件夹拷到演示用的电脑上，双击 `index.html` 就能跑
2. **手机热点**：万一现场 Wi-Fi 不通
3. **截图备份**：`docs/screens/` 里的 7 张图，实在打不开还能讲

> 经验：答辩时永远假设网络会出问题，本地能跑的那一份才是保底。

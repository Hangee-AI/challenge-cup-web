# 后端上线（让别人也能注册 / 登录 / 打卡）

> 现在的状态：
> - **https://guoguan.surge.sh** = 前端静态站，只能看页面，账号/打卡自动隐藏（Surge 跑不了 Node）
> - **http://localhost:3210** = 你这台电脑上的完整版（别人打不开，因为 localhost 只指本机）
> - 想让"任何设备都能注册登录"，要把 `server/` 部署到公网。

---

## 方案一：Render（推荐，免费、用 GitHub 登录即可，不需要手机号）

### 第 1 步：注册 / 登录

1. 打开 <https://render.com>
2. 点 **Get Started** → **GitHub** → 用 `Hangee-AI` 账号授权登录

### 第 2 步：用 Blueprint 一键部署

1. 登录后点右上 **New +** → **Blueprint**
2. 选仓库 `Hangee-AI/challenge-cup-web` → **Connect**
3. Render 会自动读到仓库里的 `render.yaml`，直接点 **Apply**
4. 等 2–3 分钟，状态变成 **Live**

### 第 3 步：拿到网址

部署完成后 Render 会给一个地址，形如：

```
https://yinlu-xxxx.onrender.com
```

这个地址**既是网页、也是接口**：打开它就能注册 / 登录 / 打卡，手机、别人的电脑都能用。

> 如果前端还想用自己的域名（如 guoguan.surge.sh），只需要在 `index.html` 里加一行：
> `<script>localStorage.setItem('yl_api_base','https://yinlu-xxxx.onrender.com')</script>`
> 或者在浏览器控制台执行一次 `localStorage.setItem('yl_api_base','https://...')`，前端就会去调那个后端。

## 需要知道的限制（免费版）

| 项目 | 说明 |
|---|---|
| 休眠 | 15 分钟没人访问会睡，下次打开要等约 30 秒唤醒 |
| **数据不持久** | 免费实例重启/重新部署后，`server/data/db.json` 会重置（账号、打卡数清零） |

> 如果希望账号**永久不丢**，有两种做法（晚点再做也行）：
> 1. 换 Railway 并挂一个 Volume（需要绑卡）
> 2. 把存储换成免费云数据库（Supabase / Neon 免费 Postgres），后端改几十行

**答辩演示建议**：用本地 `PORT=3210 npm start`（断网也能用），公网那台作为"别人也能访问"的展示。

## 常见问题

**Q：为什么 localhost:3210 别人打不开？**
A：`localhost` / `127.0.0.1` 永远指向"看网页的那台机器"。你发给别人，它指向的是对方自己的电脑，所以打不开。必须是公网域名或 IP。

**Q：Render 的免费实例会不会被人乱注册？**
A：接口每人注册限 10 次/分，够演示用；如果担心，可以在 `server/routes/auth.js` 里换成更严格的限流或者加邀请码。

**Q：部署失败提示找不到 package.json？**
A：确认仓库根目录有 `package.json`（有，`start` 脚本是 `node server/index.js`），Render 的 Root Directory 留空即可。

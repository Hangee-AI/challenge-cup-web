# 学习搭子「小引」（DeepSeek 接入说明）

右下角那只猫头鹰就是它。可以拖动、双击收起，点一下打开对话框。
它现在能做两类回答：

- **接通大模型**（配了 DeepSeek Key）→ 正常聊天，会带上「你正在看哪一关」的上下文
- **没接通**（没配 Key / 断网 / 连不上后端）→ 退回本地兜底回答：这关重点、给我一道练习、我卡住了

两种情况下页面都不会白屏，答辩演示随时能跑。

---

## 1. 为什么要经过服务器

DeepSeek 的 Key **绝对不能写进前端**，否则任何人打开 F12 都能拿到你的 Key，然后刷你的余额。

所以链路是：

```
浏览器  ──POST /api/chat──▶  本站 Node 后端  ──带 Key──▶  api.deepseek.com
        （只发对话内容）        （Key 只在服务器上）
```

前端代码：`js/pet.js`
后端代码：`server/routes/chat.js`

---

## 2. 配 Key（二选一）

### 方式 A：环境变量（推荐）

**Windows PowerShell：**

```powershell
$env:DEEPSEEK_API_KEY="sk-你的key"
$env:PORT="3000"
npm start
```

**Linux / macOS：**

```bash
DEEPSEEK_API_KEY=sk-你的key PORT=3000 npm start
```

### 方式 B：本地文件（不想每次设环境变量时用）

新建 `server/data/deepseek.json`：

```json
{ "apiKey": "sk-你的key" }
```

`server/data/` 已经在 `.gitignore` 里，**不会**被提交到 GitHub。
（仓库里有一份 `server/deepseek.example.json` 可以照着改。）

配好后打开页面，猫头鹰的副标题会从「只连着本地（未配大模型）」变成「在线 · deepseek-chat」。

### 可选环境变量

| 变量 | 默认值 | 说明 |
|---|---|---|
| `DEEPSEEK_BASE` | `https://api.deepseek.com` | 换中转/代理时用 |
| `DEEPSEEK_MODEL` | `deepseek-chat` | 换 `deepseek-reasoner` 会更慢更贵 |
| `DEEPSEEK_MAX_TOKENS` | `500` | 单次回答上限，越小越省钱 |
| `DEEPSEEK_TIMEOUT_MS` | `25000` | 超时时间 |
| `CHAT_PER_IP_HOUR` | `40` | 单个 IP 每小时最多几条 |
| `CHAT_DAILY_CAP` | `800` | 全站每天最多几条（防刷爆余额） |
| `CHAT_REQUIRE_LOGIN` | `0` | 设为 `1` 时只有本站已登录用户能对话 |

## 3. Key 从哪来、要花多少钱

- 去 <https://platform.deepseek.com> 注册，在「API keys」里创建一个 Key（`sk-` 开头）。
- **DeepSeek 官方没有永久免费额度**，是充值制；新注册一般会有少量赠送额度，够先试。
  价格以官网为准，按 token 计费，学习搭子这种短问答一次大约几厘钱。
- 想完全零成本，还有两条路：
  1. 其他平台的新用户免费额度（如硅基流动、阿里云百炼、火山方舟等，都提供 DeepSeek 模型），
     拿到它们的兼容接口地址 + Key，用 `DEEPSEEK_BASE` / `DEEPSEEK_API_KEY` 指过去即可；
  2. 本机跑 Ollama（完全免费，但要电脑跑得动模型，我可以把后端改成指向本地）。

> 比赛演示用不了多久：按 100 次问答算，成本通常不到 1 块钱。

---

## 4. 防刷：已经做了限流

`server/routes/chat.js` 里：

- 单个 IP **每小时 40 条**
- 全站 **每天 800 条**
- 单条消息最长 800 字，最多带 10 条历史
- 单次回答最多 500 tokens
- 超时 25 秒自动放弃，前端会提示「等太久了」

这几个数字都在文件顶部，想改直接改（也支持上面表格里的环境变量）。

**最狠的止损开关**：把 `CHAT_REQUIRE_LOGIN=1`，就只有在本站用学号登录过的用户能聊天；
再狠一点就把 Key 清空——猫头鹰立刻退回本地兜底回答，页面照样能演示，一分钱不花。

---

## 5. 它被约束成「学习搭子」

系统提示词写在 `server/routes/chat.js` 的 `SYSTEM_PROMPT` 里，要点：

- 中文、口语、像学长学姐，一般 3 句话以内（≤120 字）
- 先给结论，再给原因或一个动作
- 结合当前关卡举例
- 不编造课程/规定，不回答与学习无关的请求
- 不输出 Markdown 标题和表格

同时前端会把当前页面信息带过去：专业、阶段、模块、关卡名、讲解要点、本关第一题。
（见 `js/pet.js` 的 `collectContext()`）

## 6. 常见问题

**Q：猫头鹰不动 / 不出现？**
看控制台有没有 `js/pet.js` 报错；确认 `index.html` 末尾引了这个脚本。

**Q：一直显示「只连着本地（未配大模型）」？**
后端没读到 Key。检查环境变量是否在当前启动的那个终端里，或 `server/data/deepseek.json` 是否存在、JSON 格式对不对。

**Q：线上（guoguan.surge.sh）能用吗？**
能，但要满足：`js/config.js` 里的后端地址是活的（现在用的是 Cloudflare 隧道，隧道重启地址会变），
且那台后端配了 Key。隧道断了的表现是猫头鹰显示「连不上后端」。

**Q：为什么不做成真正的桌面宠物（在桌面漂浮）？**
网页只能在自己窗口里浮动。要做到「桌面级」需要打包成桌面程序（Electron / Tauri），
属于另一个工程量，比赛后再考虑；现在这个是「网页内挂件」，效果已经接近。

## 8. 换成 OpenRouter 的免费模型（不花钱、不要信用卡）

DeepSeek 官方 API 新账号没有免费额度，但 OpenRouter 上有一批 `:free` 模型可以白嫖。
代码已经内置好了，**换服务商只需要设一个环境变量**，不用改任何逻辑。

### 8.1 拿 Key（3 分钟）

1. 打开 https://openrouter.ai ，右上角 Sign in（用 GitHub 或邮箱注册，不需要手机号）
2. 进 https://openrouter.ai/keys → Create Key → 复制 `sk-or-v1-...`
3. 把 Key 交给负责服务器的人（或自己填进 `server/data/llm.json`）

### 8.2 两种填法（任选其一）

**A. 环境变量（推荐，适合部署平台）**

```bash
LLM_PROVIDER=openrouter
OPENROUTER_API_KEY=sk-or-v1-xxxx
```

**B. 文件（适合本机，不想碰环境变量）**

新建 `server/data/llm.json`（这个目录已在 .gitignore 里，不会提交）：

```json
{ "apiKey": "sk-or-v1-xxxx" }
```

### 8.3 当前默认用的模型（可换）

| 用途 | 模型 id |
|---|---|
| 主模型 | `nvidia/nemotron-3-super-120b-a12b:free` |
| 备用 1 | `google/gemma-4-31b-it:free` |
| 备用 2 | `nvidia/nemotron-3.5-lightning:free` |

主模型限流或报错时，OpenRouter 会自动退到备用模型（后端把三个一起放进 `models` 数组）。
想换主模型：`LLM_MODEL=google/gemma-4-31b-it:free`。

> 免费池是动态的，随时可能下架或换名。查当前可用的免费模型：https://openrouter.ai/models?max_price=0

### 8.4 免费额度到底有多少

- **不保证一直免费**：OpenRouter 会调整免费池，模型可能下架、限速可能是每天几十到上千次
- **有限速**：免费模型通常每分钟 20 次左右；每天总量跟账号有关（未充值较少，充过 $10 后额度更高）
- **有隐私代价**：免费模型可能拿对话数据做训练，**不要在里面输入真实隐私信息**
- 想稳定：充 $10 之后额度更高，或换回 DeepSeek/硅基流动的付费接口

### 8.5 其它服务商（同一套代码）

| LLM_PROVIDER | BASE | 需要设的 Key |
|---|---|---|
| `deepseek`（默认） | https://api.deepseek.com | `DEEPSEEK_API_KEY` |
| `openrouter` | https://openrouter.ai/api/v1 | `OPENROUTER_API_KEY` |
| `siliconflow` | https://api.siliconflow.cn/v1 | `SILICONFLOW_API_KEY` |
| `ollama`（本机跑，0 元） | http://127.0.0.1:11434/v1 | 不需要 |
| `custom` | 自己填 `LLM_BASE` | `LLM_API_KEY` |

验证是否接通：打开 `http://localhost:3210/api/chat/status`，
`ready:true` 且 `providerLabel` 是你要的那家，就成功了；页面上猫头鹰的状态栏会显示「在线 · 服务商 / 模型名」。

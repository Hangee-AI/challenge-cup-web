# challenge-cup-web

第二十届"挑战杯"南昌大学大学生课外学术科技作品竞赛 · 院赛参赛作品
**面向新生的编程闯关学习系统**

> 一句话：让想自学编程但不知道从哪下手的大一新生，选完专业和喜欢的学习方式后，能被一步一步带着闯关学下去。

## 目录结构

```
challenge-cup-web/
├─ index.html          入口页（选择专业 / 兴趣 / 学习形式）
├─ css/                样式
├─ js/                 交互与判题逻辑
├─ data/               题库与关卡配置（questions.json）
├─ assets/             图片、音效等素材
├─ docs/               申报书、答辩稿等文档
└─ README.md
```

## 本地运行

目前是纯静态页面，直接用浏览器打开 `index.html` 即可。
（后续如引入构建工具，再补 `npm install` 步骤。）

## 开发约定

1. **开工先 `git pull`，收工必 `git push`**。
2. **一人一文件**：各自只改自己负责的文件，减少冲突。
3. **`main` 分支必须随时可运行**（答辩要能演示），日常开发在 `dev` 分支。
4. 提交信息写清楚做了什么，例如：`feat: 完成第3关题目数据`。
5. 不提交视频、原始大图、`node_modules`。

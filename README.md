# challenge-cup-web

第二十届"挑战杯"南昌大学大学生课外学术科技作品竞赛 · 院赛参赛作品
**引路 —— 大学新生专业学习导航**

> 一句话：新生不是不努力，是不知道"该学什么、先学什么"。选一个专业，我们把四年拆成阶段、模块和一关一关的小任务，让学生知道下一步该干什么。

线上演示地址：<https://guoguan.surge.sh>

## 当前版本做了什么（v9 改版）

体验主线：**首页 → 选专业 → 选讲解方式 → 我的路径 → 闯关地图 → 讲解（文档 / 视频）→ 答题 → 学习报告 / 个人中心**

- **首页（v9 重做）**：左边主标语 + 两个入口；右侧换成 **「继续上次」卡**（记着你上次学到哪一关、用哪种方式）+ **每日鼓励语**（点「换一句」随机换）；下方是 **公告轮播**（B 站式左右箭头 + 圆点、5 秒自动切换、鼠标悬停暂停，给以后的更新记录和使用说明用）；再下面是 13 门类入口、三步流程、底部换成数字条（13 门类 / 49 专业 / 165 集 / 7 关 / ∞）。
- **主题模式（v9 新增）**：导航右上角「☀️ 晨雀 / 🌙 夜猫」一键切换白底 / 黑底，选择记在本地（`html[data-theme="night"]` 覆盖全部颜色变量），刷新后保持；个人中心里也有切换入口。
- **个人中心（v9 新增）**：导航右侧「👤 登录 / 头像+昵称」进入。
  - **游客模式**：不登录也能正常选专业、闯关、记时长，数据只存在这台设备。
  - **常驻模式**：填**学号**（6–20 位数字）即可注册，**不需要密码**，昵称留空则自动取「同学 + 学号后四位」，再从 16 个 emoji 里挑头像；注册后显示学号、加入日期、累计学习时长、连续天数、通关数、答题数、正确率、星星，以及最近 7 天的学习时长柱状图。
  - 学习时长统计：页面可见时每 15 秒记一次，切到后台就停。
- **自动恢复上次学习位置（v9 新增）**：无论视频还是文字，`openLevel` / 选集 / 文档滚动都会记住位置（`state.last`），首页「接着学」直接回到那一关；视频会回到上次那一集，文档会滚回上次读到的位置。
- **真正的首页**：产品介绍、路径预览、13 个学科门类入口、四步流程。
- **专业库（参与式选择）**：13 个学科门类、49 个常见专业；**选定专业后，页面只显示这个专业的内容**；顶部常驻「当前专业」和一个「重新选择」按钮，随时能换。
- **选讲解方式**：**文字说明**和**视频讲解**都已可用。入口有三处：①「我的专业」页一排大按钮 ②「我的路径」页顶部「讲解方式」切换 ③文档页/视频页底部「换成另一种」——点一下立刻按新方式打开同一关。
- **专业路径页**：每个专业自动生成「4 个阶段 × 3 个模块 × 3 个关卡」的路径框架。
- **闯关地图页**：把所有已就绪的关卡按阶段排成一条闯关路线，分「已通关 / 可挑战 / 未解锁」三态，**完成前一关才会解锁下一关**。
- **文字说明 = 文档站（v4）**：仿 csdiy.wiki 三栏——左边「整个专业路径的目录」（阶段 → 模块 → 关卡，可滚动）、中间正文（小节、代码块、提示块）、右边「本页目录」；底部是延伸资源（指向 csdiy.wiki）和「读完，开始做题」。
- **视频讲解 = B 站课程 + 目录（v5 新增）**：课程是黑马程序员《C语言零基础入门到精通》165 集；左边是整门课的**章节目录（14 章 165 集，可滚动）**，右边是 16:9 播放器播放「本关对应的分集」，下面是本关必看 / 想深挖再看的选集卡，点一下就能换集。播放器打不开时可直接跳 B 站看，目录与做题不受影响。
- **关卡页**：只留答题（讲解在文档页/视频页）→ 即时判对错 → 说明为什么错 → 记录进度与星级。
- **学习报告页**：完成关卡数、累计答题、正确率、星星、逐关记录。
- 进度存在浏览器 localStorage（key = `yinlu_v1`），关掉网页再打开还在。

> 框架优先：路径与地图结构是完整的，但具体内容目前只有「计算机科学与技术 → 大一 → C 语言入门」有 7 个真实关卡 + 7 篇完整文档 + 7 组对应分集（覆盖 runoob C 教程 7 大主题），其余模块显示"建设中"，由团队后续按培养方案补充。
>
> 📚 文档正文是**自己写的**，csdiy.wiki 只作为「延伸资源」推荐，页脚已注明「本站只做推荐，不转载其内容」；视频用 B 站官方播放器嵌入，版权归原作者，本站仅做课程推荐。
>
> 🗺️ 闯关地图目前是**结构版**（阶段分组 + 节点），视觉模板待定稿后替换；替换时只改 `.map-*` 相关样式和 `renderMap()` 的 DOM 结构，数据不用动。

## 本地运行

纯静态页面，无构建、无依赖：直接双击 `index.html`，或者用本地文件地址打开即可。

> 注意：数据放在 `js/data.js` 里而不是 `.json` + fetch，因为 `file://` 协议下浏览器会拦截 fetch（CORS）。所以**不要**把数据改成外部 JSON 文件。

## 修改指引（给队友）

| 想改什么 | 改哪个文件 | 怎么改 |
|---|---|---|
| 加 / 改专业 | `js/data.js` 顶部 `MAJOR_ROWS` | 一行一个：`['门类id','专业名','图标','一句话方向']` |
| 改路径阶段/模块 | `js/data.js` 的 `PATH_TEMPLATE` | 每个门类 4 个阶段，每个阶段 3 个模块 |
| 加真实关卡题目 | `js/data.js` 的 `CS_INTRO_LEVELS` 格式 | `{ name, brief, questions:[{stem, options, answer, explain}] }` |
| 改讲解方式 | `js/data.js` 的 `STYLES` | 目前「视频讲解 / 文字说明」，加第三种照格式补一条；页面上所有切换按钮共用 `[data-switch-style]` |
| 改闯关地图外观 | `css/style.css` 的 `.map-*` + `js/app.js` 的 `renderMap()` | 数据层不用动，只换 DOM/样式 |
| **改某关的文档正文** | `js/docs.js` 的 `DOCS` | key 用关卡 id（如 `engineering-计算机科学与技术-m0-l0`），值是 `{lead, sections:[{id,title,html}], refs}` |
| **加某个专业的文档** | `js/docs.js` 顶部新增 key（或改 `makeGenericDoc()` 里的通用模板） | 没有专门文档的关卡会自动用通用模板，不会白屏 |
| **换视频课程** | `js/videos.js` 顶部 `BV_ID / BV_TITLE / BV_TOTAL` + `BV_CHAPTERS` | 换 B 站课程时重新生成章节数组；播放器地址由 `bvPlayerUrl()` 拼 |
| **改某关对应哪几集** | `js/videos.js` 的 `VIDEO_MAP` | `main` 是本关必看、`extra` 是可选；都是 `[起始集, 结束集]`，没配的关卡用 `VIDEO_DEFAULT` |
| 改文档页三栏布局 | `css/style.css` 的 `.doc-*` | 左栏 `.doc-side`、右栏 `.doc-toc`、正文 `.doc-main` |
| 改视频页布局 | `css/style.css` 的 `.video-* / .player-* / .ep-*` | 左栏目录 + 右栏播放器，`.video-wrap` 控制两栏宽度 |
| **改首页公告** | `js/data.js` 的 `ANNOUNCEMENTS` | 一条一个 `{tag, emoji, tone, title, desc}`，`tone` 决定渐变底色 |
| **改首页鼓励语** | `js/data.js` 的 `HOME_QUOTES` | 直接加字符串，一行一句 |
| **改可选头像** | `js/data.js` 的 `AVATARS` | 加 emoji 即可，注册页自动渲染 |
| **改主题配色** | `css/style.css` 的 `html[data-theme="night"]` | 只在夜间块里覆盖同名的 `:root` 变量，别改上面默认值 |
| **改学习时长统计** | `js/app.js` 的 `startStudyTimer()` | 现在是「可见时每 15 秒 +15 秒」，改间隔/步长都在这里 |
| **改续学记忆** | `js/app.js` 的 `remember()` / `resumeLast()` | 记的是 `{majorId, levelId, mode, page, docY, ts}`，字段加在这里 |
| 改样式 | `css/style.css` | 颜色统一用顶部 `:root` 变量 |
| 改页面结构 | `index.html` + `js/app.js` | 视图 id 必须保留 `view-*` 命名 |

改完自测：把「首页 → 选专业 → 选讲解方式（文字说明）→ 我的路径 → 闯关地图 → 点关卡进文档页（左目录/正文/右目录都在）→ 读完开始做题 → 判对错 → 返回地图（下一关已解锁）→ 学习报告」整条路走一遍；再切一次「视频讲解」，进关卡确认左边 165 集目录能滚动、右边播放器是本关那几集、点选集能换集，最后点「看完，开始做题」能进答题。 另外再确认四点：①导航右上角切一次「夜猫 / 晨雀」看整站是否都变成深色 / 浅色、刷新后是否保持；②点「登录」用学号注册一次，个人中心应出现昵称、头像、学号、统计与 7 天柱状图；③随便进一关读两段 / 播一集，回首页应出现「继续上次 + 接着学」，点它能回到同一关同一位置；④首页公告轮播左右箭头、圆点、5 秒自动切换、鼠标悬停暂停都正常。

## 开发约定

1. **开工先 `git pull`，收工必 `git push`**。
2. **一人一文件**：各自只改自己负责的文件，减少冲突。
3. **`main` 分支必须随时可运行**（答辩要能演示），日常开发在 `dev` 分支。
4. 提交信息写清楚做了什么，例如：`feat: 补充高数模块的 3 个关卡`。
5. 不提交视频、原始大图、`node_modules`。
6. 提交历史本身就是"作品是团队自己做的"的佐证，**不要用网盘传 zip 代替 git**。

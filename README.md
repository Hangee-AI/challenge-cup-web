# challenge-cup-web

第二十届"挑战杯"南昌大学大学生课外学术科技作品竞赛 · 院赛参赛作品
**引路 —— 大学新生专业学习导航**

> 一句话：新生不是不努力，是不知道"该学什么、先学什么"。选一个专业，我们把四年拆成阶段、模块和一关一关的小任务，让学生知道下一步该干什么。

线上演示地址（surge.sh，随 main 推送由 GitHub Actions 自动部署）：<https://guoguan.surge.sh>

## 当前版本做了什么（v9 改版）

体验主线：**首页 → 选专业 → 选讲解方式 → 我的路径 → 闯关地图 → 讲解（文档 / 视频）→ 答题 → 学习报告 / 个人中心**

- **首页（v9 重做）**：左边主标语 + 两个入口；右侧换成 **「继续上次」卡**（记着你上次学到哪一关、用哪种方式）+ **每日鼓励语**（点「换一句」随机换）；下方是 **公告轮播**（B 站式左右箭头 + 圆点、5 秒自动切换、鼠标悬停暂停，给以后的更新记录和使用说明用）；再下面是 13 门类入口、三步流程、底部换成数字条（13 门类 / 49 专业 / 165 集 / 7 关 / ∞）。
- **主题模式（v9 新增）**：导航右上角「☀️ 晨雀 / 🌙 夜猫」一键切换白底 / 黑底，选择记在本地（`html[data-theme="night"]` 覆盖全部颜色变量），刷新后保持；个人中心里也有切换入口。
- **个人中心（v9 新增）**：导航右侧「👤 登录 / 头像+昵称」进入。
  - **游客模式**：不登录也能正常选专业、闯关、记时长，数据只存在这台设备。
  - **常驻模式**：先选**学校简称**（NCU / JXNU / NCHU 等 10 个）再填**学号**（6–20 位数字）即可注册，**不需要密码**（直接粘贴 `NCU9110126060` 这类完整账号也能识别，前缀以粘贴内容为准）；账号只写本机 localStorage，昵称留空则自动取「同学 + 学号后四位」，再从 16 个 emoji 里挑头像；注册后显示学号、加入日期、累计学习时长、连续天数、通关数、答题数、正确率、星星，以及最近 7 天的学习时长柱状图。
  - 学习时长统计：页面可见时每 15 秒记一次，切到后台就停。
- **自动恢复上次学习位置（v9 新增）**：无论视频还是文字，`openLevel` / 选集 / 文档滚动都会记住位置（`state.last`），首页「接着学」直接回到那一关；视频会回到上次那一集，文档会滚回上次读到的位置。
- **真正的首页**：产品介绍、路径预览、13 个学科门类入口、四步流程。
- **专业库（参与式选择）**：13 个学科门类、49 个常见专业；**选定专业后，页面只显示这个专业的内容**；顶部常驻「当前专业」和一个「重新选择」按钮，随时能换。
- **选讲解方式**：**文字说明**和**视频讲解**都已可用。入口有三处：①「我的专业」页一排大按钮 ②「我的路径」页顶部「讲解方式」切换 ③文档页/视频页底部「换成另一种」——点一下立刻按新方式打开同一关。
- **专业路径页**：每个专业自动生成「4 个阶段 × N 个模块 × 3 个关卡」的路径框架；**计算机科学与技术专业已按南昌大学数学与计算机学院《计算机科学与技术培养方案（2024 版）》替换为真实课程**：大一 6 门（C 语言入门 / 计算机导论与伦理 / 高等数学（上）（下） / 线性代数 / 面向对象程序设计 Java）、大二 7 门（数据结构 / 离散数学 / 数字逻辑 / 计算机组织与结构 / 概率论与数理统计 / 数据库原理 / 数值计算）、大三 6 门（操作系统 / 编译原理 / 计算机网络 / 软件工程 / 算法分析与设计 / 人工智能）、大四 4 门（毕业实习 / 毕业设计 / 工程实践 / 计算机网络课程实践），共 24 个模块。
- **闯关地图页**：把所有已就绪的关卡按阶段排成一条闯关路线，分「已通关 / 可挑战 / 未解锁」三态，**完成前一关才会解锁下一关**。
- **文字说明 = 文档站（v4）**：仿 csdiy.wiki 三栏——左边「整个专业路径的目录」（阶段 → 模块 → 关卡，可滚动）、中间正文（小节、代码块、提示块）、右边「本页目录」；底部是延伸资源（指向 csdiy.wiki）和「读完，开始做题」。
- **视频讲解 = B 站课程 + 目录（v5 新增）**：课程是黑马程序员《C语言零基础入门到精通》165 集；左边是整门课的**章节目录（14 章 165 集，可滚动）**，右边是 16:9 播放器播放「本关对应的分集」，下面是本关必看 / 想深挖再看的选集卡，点一下就能换集。播放器打不开时可直接跳 B 站看，目录与做题不受影响。
- **关卡页**：只留答题（讲解在文档页/视频页）→ 即时判对错 → 说明为什么错 → 记录进度与星级。
- **学习报告页**：完成关卡数、累计答题、正确率、星星、逐关记录。
- 进度存在浏览器 localStorage（key = `yinlu_v1`），关掉网页再打开还在。

## v12 新增：服务器账号 · 每日打卡 · 照明看板

> 这一版加了真正的后端（`server/`，Express + JSON 文件存储）。**有后端就用账号体系，没后端自动退回本地模式**，双击 `index.html` 照样能演示，不会报错。

- **账号体系（服务器）**
  - 注册：学校简称 + 学号 + **密码**（6–32 位）；密码用 `scrypt` 加盐哈希存，不存明文。
  - 登录 / 退出：登录后拿到 30 天有效的 token（存在浏览器），个人中心显示「云端账号」。
  - **忘记密码**：只输入「注册时的学校简称 + 学号」即可直接重设密码，**不需要邮箱和手机验证**（按需求方指定的方案）。
  - **修改密码**：输入原密码 + 新密码（两次），校验原密码通过才更新。
  - 接口：`POST /api/auth/register|login|reset|change|logout`、`GET /api/auth/me`，都有简单限流（注册 10 次/分、登录 20 次/分）。
- **每日打卡**
  - 登录后点「今日打卡」，同一天只算一次（幂等），返回今日打卡人数与个人连续天数。
  - 接口：`POST /api/checkin`（需登录）。
- **照明 / 点亮效果**
  - 每个新访客（浏览器指纹）第一次进入时，会全屏播放一次「💡 已为你点亮一盏灯 · 你是第 N 个被照亮的人」的光晕动画（每台设备只播一次）。
  - 首页看板展示：**今日打卡人数**、**已为多少人照明引路**、**我的连续打卡**；数字来自 `GET /api/stats`，点亮来自 `POST /api/light`。
  - 注册成功也算一次点亮（账号即一盏灯）。
- **前端接线**：新增 `js/cloud.js`——先用 1.8 秒超时探测 `/api/ping`，在线才显示云端入口（注册/登录/忘记密码三个 tab、打卡按钮、修改密码），离线则自动隐藏这些入口，页面其余部分完全不受影响。

> 框架优先：路径与地图结构是完整的，但具体内容目前只有「计算机科学与技术 → 大一 → C 语言入门」有 7 个真实关卡 + 7 篇完整文档 + 7 组对应分集（覆盖 runoob C 教程 7 大主题），其余模块显示"建设中"，由团队后续按培养方案补充。
>
> 📚 文档正文是**自己写的**，csdiy.wiki 只作为「延伸资源」推荐，页脚已注明「本站只做推荐，不转载其内容」；视频用 B 站官方播放器嵌入，版权归原作者，本站仅做课程推荐。
>
> 🗺️ 闯关地图目前是**结构版**（阶段分组 + 节点），视觉模板待定稿后替换；替换时只改 `.map-*` 相关样式和 `renderMap()` 的 DOM 结构，数据不用动。

## 本地运行

**方式一（纯静态，推荐用来快速看页面）**：直接双击 `index.html`。此时没有后端，账号 / 打卡 / 照明看板会自动隐藏。

**方式二（带后端，完整功能）**：

```bash
npm install
npm start          # 默认 http://localhost:3000，被占用就换端口：PORT=3210 npm start
```

打开 <http://localhost:3000>，个人中心就会出现「注册 / 登录 / 忘记密码」和服务器的打卡、照明人数。

> 注意：数据放在 `js/data.js` 里而不是 `.json` + fetch，因为 `file://` 协议下浏览器会拦截 fetch（CORS）。所以**不要**把静态内容改成外部 JSON 文件。
>
> 账号数据存在 `server/data/db.json`（已在 `.gitignore` 里，不会提交），删掉这个文件就等于清空所有账号。

## 开发约定

1. **开工先 `git pull`，收工必 `git push`**。
2. **一人一文件**：各自只改自己负责的文件，减少冲突。
3. **`main` 分支必须随时可运行**（答辩要能演示），日常开发在 `dev` 分支。
4. 提交信息写清楚做了什么，例如：`feat: 补充高数模块的 3 个关卡`。
5. 不提交视频、原始大图、`node_modules`。
